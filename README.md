Redirect stub for the old `info-arena.github.io/ARENA_img/...` URLs.

`ARENA_img` now lives at https://github.com/ARENA-education/ARENA_img and is
served from https://arena-education.github.io/ARENA_img/.

- `404.html` forwards any `/ARENA_img/...` path to the new site (covers the
  embedded `.html` figures).
- `ARENA_img/` holds frozen copies of the few images and videos that old
  material loads directly from this address, since those cannot be redirected.
